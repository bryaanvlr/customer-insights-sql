# Customer Insights SQL

Projeto em SQL para analisar compras, gastos e comportamento dos clientes.

A ideia foi trabalhar com um banco de dados de clientes e pedidos e responder perguntas que poderiam aparecer em uma análise real de negócio.

## Tecnologias

- SQL
- SQLite
- VS Code

## Análises realizadas

- Clientes que mais realizaram compras
- Ticket médio dos clientes
- Identificação de clientes recorrentes
- Quantidade de compras e total gasto por cliente
- Clientes que mais geraram receita
- Top 10 clientes por receita
- Identificação de clientes VIP

## Conceitos utilizados

- SELECT
- WHERE
- JOIN
- GROUP BY
- HAVING
- COUNT
- SUM
- AVG
- ORDER BY
- LIMIT

## Objetivo

Praticar consultas SQL voltadas para análise de dados e transformar informações do banco em respostas úteis para o negócio.
